更新 GitHub 的方式：
1. 解壓縮此 ZIP。
2. 開啟 GitHub 專案，按 Add file → Upload files。
3. 一次選取解壓縮資料夾裡的所有 .html 檔案（不要把 README 當網站頁面上傳也可以）。
4. 確認檔名與網站根目錄中的檔名相同，再按 Commit changes。

注意：這包只更新 HTML，不包含或覆蓋圖片等其他網站資源。
